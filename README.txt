JANARTHANAN R — CYBERSECURITY PORTFOLIO

FILES
- janarthanan_portfolio_191_frames.html: the portfolio webpage, updated for 191 frames.

HOW TO USE WITH YOUR EXISTING FOLDER
1. Keep your existing portfolio folder and its `frames` subfolder.
2. Copy this HTML file into the main `portfolio` folder.
3. Rename it to `index.html` if this should be the main page (back up any existing index.html first).
4. Your frames folder should contain img_00001 through img_00191. Mixed .jpg, .jpeg, .png, .webp, and .bmp extensions are supported.
5. Open index.html in a browser to test. For best results, use VS Code Live Server.

NOTES
- The page uses the filenames created by your PowerShell script.
- This package does not contain your 191 local frame images; keep those in the `frames` folder.
- Resume download is not enabled because the actual PDF has not been provided.
